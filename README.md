# Мини-система бронирования (VPc07)

Учебный проект zerocoder: база данных PostgreSQL + CRUD + графический
интерфейс. Три таблицы (пользователи, столики, бронирования), запрет
пересечения времени брони по одному столику, живая проверка доступности
в GUI.

## Структура проекта

| Файл | Что делает |
|---|---|
| `postgres_driver.py` | Курсовой драйвер: подключение из `.env`, `select`/`execute`, автосоздание таблиц из моделей |
| `models/` | Три модели данных: `user`, `tables`, `booking` |
| `backend.py` | CRUD всех трёх таблиц, проверка пересечений, демо-данные |
| `app.py` | Графический интерфейс (tkinter): три вкладки, добавление/удаление, проверка доступности |
| `checks.py` | Сценарий приемки: все проверки одной командой |
| `.env` | Подключение к базе (пароль только здесь, в гит не попадает) |

## Как запустить

Нужен PostgreSQL на localhost:5432 и созданная база `booking`
(пользователь и пароль прописываются в `.env` — см. ниже).

1. Рядом с файлами проекта создать файл `.env` по образцу `.env.example`
   и вписать пароль пользователя базы:

   ```
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=booking
   DB_USER=zerocoder
   DB_PASSWORD=пароль
   ```

2. Создать окружение и установить пакеты:

   ```
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   ```

3. Наполнить базу демо-данными (создаёт таблицы и 3 юзера / 3 столика /
   2 брони, если база пуста):

   ```
   ./venv/bin/python backend.py
   ```

4. Открыть графический интерфейс:

   ```
   ./venv/bin/python app.py
   ```

## Проверка (сценарий приемки)

```
./venv/bin/python checks.py
```

Прогоняет все проверки одной командой и печатает `[OK]`/`[FAIL]` по
каждой. В проверку заложен крайний случай: попытка поставить бронь в
занятое время обязана быть отвергнута, а стык «кончается в 20:00 —
новая начинается в 20:00» — обязана пройти.

Важно: приёмка рассчитана на демо-данные — ровно 3 юзера, 3 столика,
2 брони. Если до прогона что-то добавить или удалить через GUI, часть
счётчиков покажет FAIL. В этом случае очисти таблицы в PgAdmin и снова
запусти `./venv/bin/python backend.py`.
